### Quick Start

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Open Gallery:**
   Navigate to [http://localhost:5173/](http://localhost:5173/) or `http://localhost:5173/YOUR_GOOGLE_DRIVE_FOLDER_ID`.
